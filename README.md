# node-express-starter

> **Archived:** This legacy starter is no longer maintained. For new projects, use an official framework generator or [Create Preset](https://github.com/preset-cli/create-preset) with a project-owned JSON preset.
>
> **已归档：** 此旧版模板已停止维护。新项目请使用框架官方生成器，或通过新版 [Create Preset](https://github.com/preset-cli/create-preset) 使用项目自行维护的 JSON preset。

This template should help you quickly create an express server project, using JavaScript as the development language by default.

这个模板应该能帮你快速创建一个基于 Express 的 Node 服务端项目，默认使用 JavaScript 作为开发语言。
